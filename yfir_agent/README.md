# yfir agent

Reports this Home Assistant host to a [yfir](https://github.com/twish/yfir)
hub: its facts, metrics, logs, containers and listening services, so it shows
in the hub's inventory, map, dashboards and rules like any other host. The
agent observes; it does not change the host.

See the Documentation tab for the options, the grants the app asks for and
why, and what to check when the host does not come online.
